# Missions KAI-EXEC

Chaque fiche suit la boucle du §12 : **définir → planifier → exécuter →
vérifier → critiquer → corriger → revérifier → valider**.

Chaque fiche contient deux rapports **séparés** (§13) :

- **Rapport créateur** — ce qui a été construit, les commandes, les fichiers,
  les hypothèses.
- **Rapport vérificateur** — les contrôles menés à partir des critères, les
  preuves, les anomalies, le verdict.

Le vérificateur ne retient jamais « la commande s'est terminée sans erreur »
comme preuve. Il teste le comportement observable.
